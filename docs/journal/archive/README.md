# Journal archive

Rotated decision-log entries. When `DECISIONS.md` grows large enough to be a
per-session load cost, whole sprint sections are **moved here verbatim** —
never deleted. The append-only guard (`scripts/ops/check_journal_append.sh`)
treats active + archive as one union, so rotation passes and deletion fails.

Distilled, generalized takeaways live in `../LESSONS.md` (the carry-forward
layer); this directory is the full raw record.
