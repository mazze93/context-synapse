# Code review grounded in the codegraph fold

**Run:** `python3 tools/codegraph/codegraph.py --repo . --out codegraph-vault` at `bb02bf263ea4`.
643 nodes, 2,983 edges, 130 commits. Fold law holds for 130/130 commits, and folding
the 112 first-parent deltas from empty reproduces HEAD. Call-site resolution: 2,973 exact,
410 unique, 112 ambiguous (ambiguous edges are kept in the vault, left out of the matrices).

Every claim below says how it was checked: **graph** (a query over `_data/graph.json`),
**code** (read at the cited line), **numeric** (a Python replica of the Swift arithmetic),
or **general knowledge** (not observed in this repo).

## Correction to the earlier circuit review

The earlier review (finding 1) said the `hashValue` schema hash means "the T5 stale-prior
protocol fires every time". **That overstated it, and I'm withdrawing that part.** The
graph shows `CircuitSnapshot` is built only by `SynapticCircuit.snapshot()`, and the only
non-test caller of `snapshot()` is `FaultInjectionSuite.runFullSuite()`. No code decodes a
snapshot or compares `schemaHash`, so nothing fires today. The bug is real but latent (see 1).

## Findings

### 1. Schema hash is process-seeded (latent)
- **code** `SynapticCircuit.swift:424-428` hashes with `String((nodeKeys + edgeKeys).hashValue)`.
- **general knowledge** Swift seeds `Hasher` per process unless `SWIFT_DETERMINISTIC_HASHING` is set, so the value differs between launches.
- **graph** no reader of `schemaHash` outside tests; `testSnapshotSchemaHashIsStableWithNoChanges` compares two hashes in one process, so it cannot catch this.
- **Fix before snapshots are persisted:** SHA-256 over the sorted, joined keys.

### 2. `widenUncertainty` lowers the mean, and often lowers the variance too
- **code** `CircuitTypes.swift:153-156` does `beta += amount`. The doc comment on `propagateUncertainty` says "never shifts target mean".
- **numeric** widening by 0.1: the mean always falls, and the variance *falls* for many priors, the default included:

  | prior | mean before → after | variance before → after |
  |---|---|---|
  | Beta(1,1) uninformed | 0.500 → 0.476 | 0.0833 → 0.0805 |
  | Beta(2,2) | 0.500 → 0.488 | 0.0500 → 0.0490 |
  | Beta(1,3) | 0.250 → 0.244 | 0.0375 → 0.0362 |
  | Beta(8,2) lighthouse | 0.800 → 0.792 | 0.0145 → 0.0148 |
  | Beta(1,0.5) | 0.667 → 0.625 | 0.0889 → 0.0901 |

  So on an uninformed neighbour, "widening" makes it *more* confident and less useful.
- **code** the test named `testWidenUncertaintyDoesNotChangeMean` (`Tests/SynapticCircuitTests.swift:230`) says in its own comment that the mean changes, and asserts only that alpha is unchanged. The name is false.
- **Fix:** scale both counts by k < 1 (mean kept, evidence weight down, variance up), keep `minimumAlpha`, and rename or rewrite the test to assert mean-preservation and variance increase.

### 3. The 0.15 uncertainty threshold cannot be reached
- **code** `init` and `update` floor alpha at 1.0; `init` floors beta at 0.01.
- **numeric** over alpha ≥ 1 the Beta variance peaks at 0.0902 (alpha 1, beta 0.618); a 25M-point grid agrees. `instabilityUncertaintyThreshold` is 0.15, so `isEpistemicallyUnstable` is driven only by prediction error.
- **graph** that flag is persisted: `SynapseManager.observe` stores backward-pass `epistemicallyUnstable` in `EpochSnapshot`.
- Caveat: `SynapticPrior` uses synthesized `Codable`, which bypasses `init`, so a decoded prior could have alpha < 1. No decode path exists today.
- **Fix:** pick a threshold the state space can reach (for example 0.06), or normalise uncertainty by its maximum.

### 4. Fault "collapse" by mean is unreachable; collapse by depth is reachable
- **code** `isPathological` is `depth >= 5 || (pre > 0.6 && post < 0.2)`. `injectFault` applies one update with eta = 0.1 × 2.5 = 0.25 at pass 0 (lower later).
- **numeric** the mean branch needs eta > 4α − β > 3.33 for any prior with pre > 0.6; the maximum eta is 0.25. A brute-force sweep (alpha, beta, lastPrediction, severity) found 0 hits; the lowest post-mean among pre > 0.6 priors was 0.524. Beta(8,2) moves 0.800 → 0.780 at most (the earlier review said about 0.017; the worst case is 0.0195).
- **code** the depth branch is reachable: a 5-hop chain where `severity × weight × 0.3 > 0.05` qualifies.
- **code** the collapse tests (`SynapticCircuitTests.swift:553-585`) use hand-built reports, so they never exercise the arithmetic.
- **Knock-on:** `recommendedAmplifier` caps at 1.5, which is the current static value. Worst-case drift gives 1.03 (lighthouse), 1.09 (uninformed), 1.33 (Beta(1,0.01)). It can only ever recommend lowering the amplifier. Its doc comment says the range is [1.0, 1.67]; the formula's range is [1.0, 1.5].

### 5. Amplifier naming conflict
- **code** ADR-003-004 says the error amplifier "does not replace" ROT_LAMBDA_AMPLIFIER. `CircuitTypes.swift:69-73` says it "Replaces static ROT_LAMBDA_AMPLIFIER". `INTEGRATION.md:98` says to update `errorDecayAmplifier` with `recommendedRotLambdaAmplifier`. Three sources, two meanings. Pick one and fix the other two.

### 6. New: the circuit is computed but not wired into the weights
- **graph** `lighthouseFloor(for:isLighthouse:)`, `predictionError(for:)` and `connectivityFactor(for:)` have test callers only. `errorDecayAmplifier` has no reader. The whole `FaultInjectionSuite` (`runFullSuite`, `runTargetedSuite`, `auditLighthouses`) has no non-test caller.
- **code** `SynapseManager` holds `private let circuit = SynapticCircuit()`, registers nodes as `.uninformed`, and discards the forward pass (`_ = await circuit.forwardPass()`, line 167). Priors live only in memory.
- **Meaning:** the INTEGRATION.md recipe is not implemented, the ADR-004 bootstrapping discount has nothing to apply to yet, and findings 2-4 only reach users through the persisted instability flag. This is the main structural gap; it also lowers the urgency of 1.

### 7. Smaller graph leads
- **graph** `EventLedger` (the append-only event path) has no test that constructs it (`grep EventLedger Tests/` finds nothing). 64 of 195 non-test functions have no test reach; that count undercounts reach through protocols and closures.
- **graph** file cycles: `AppMain ↔ ContentView`, `LighthouseStore ↔ SynapseManager`, `SynapseCore ↔ UserStorage`. No type-level cycles.
- **graph** churn: `SynapseCore` changed in 18 commits and has the highest fan-in (14 types, 19 files). It is the place a split would pay off.
- **graph** `SynapseCore.maybeInjectFaults(into:)` calls `random()` 7 times; fine for a feature, but runs that use it are not reproducible without a seeded generator.

## Tool limits found during this review (failing loudly)
- `EventLedger.csvEscape(_:)` is listed as an uncalled private function. It is used as a function reference, `.map(EventLedger.csvEscape)` (`EventLedger.swift:199`). The resolver only sees calls with parentheses. Treat the "uncalled private" list as leads, and fix by emitting `references` edges for qualified member names.
- Resolution is by name, without type inference. Protocol dispatch and closures are undercounted.
